# Build a guided desktop workbench

The prototype will be a desktop-first RM workbench with a calm, premium private-banking visual tone and restrained use of urgency colors. It will use only the supplied synthetic data and demonstrate production security, entitlement, audit, and deployment considerations through a target architecture rather than attempting to build bank infrastructure. AI interaction will use bounded Guided Actions instead of an open chatbot so outputs remain grounded and the demo follows the intended advisory workflow.
