# Domain docs

This repository uses a single domain context.

Before exploring or implementing JB Clarity behavior, read:

- `CONTEXT.md` for canonical domain language
- Relevant decisions under `docs/adr/`
- The assigned issue and the build specification it references

Use glossary terms in issue titles, interfaces, tests, and UI copy. Surface any conflict with an ADR instead of silently overriding it. General implementation details do not belong in `CONTEXT.md`.
