# Triage labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Product owner must evaluate the issue |
| `needs-info` | `needs-info` | More information is required before execution |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AI agent |
| `ready-for-human` | `ready-for-human` | Requires human-only action |
| `wontfix` | `wontfix` | Intentionally excluded |
